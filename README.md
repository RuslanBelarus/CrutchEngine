## О проекте

**Crutch Engine (Demo) patch-2** — это простая «костыльная» среда для создания 2D-игр.  
Проект состоит из двух частей:

1. **Редактор** — визуальное редактирование объектов, скриптов, текстур, шрифтов и параметров проекта.
2. **Рантайм** — запуск игры по данным из JSON-файлов.

Данные разделены на два уровня:

- `project.json` — настройки проекта, палитра редактора, имя, версия, описание, путь к файлу данных.
- `data.json` — объекты игры, скрипты, текстуры, шрифты и параметры экрана.

По умолчанию используется окно **24×18 тайлов** по **32 пикселя**, то есть **768×576**, частота **60 FPS**, полноэкранный режим выключен.

## Форматы данных

### `data.json` — данные игры

```json
{
  "project_options": {
    "screen_tiles": [24, 18],
    "screen_scale": 32,
    "screen_fullscreen": false,
    "screen_title": "Example project",
    "fps": 60,
    "debug": false
  },
  "fonts": {},
  "textures": {},
  "scripts": {},
  "game_objects": []
}
```

### `project.json` — настройки проекта и редактора

```json
{
  "project_name": "Example project",
  "project_description": "We dont need in decription :D",
  "project_version": "1.0",
  "datafile": {
    "file": "data.json"
  },
  "editor_pallete": {
    "background": [0, 0, 0],
    "plate": [20, 20, 20],
    "text": [255, 255, 255],
    "hovertext": [170, 170, 170],
    "exception": [255, 0, 0]
  },
  "background": null
}
```

### Поля игровых объектов

| Поле | Назначение |
|---|---|
| `type` | Тип объекта: `object`, `text`, `empty` |
| `uuid` | Уникальное имя объекта |
| `x`, `y` | Позиция |
| `width`, `height` | Размер для `object` |
| `color` | Цвет `[R, G, B]` |
| `texture` | Имя текстуры из `textures` |
| `text` | Текст для `text` |
| `font` | Имя шрифта из `fonts` |
| `scene` | Сцена; `null` — объект на всех сценах |
| `script` | Имя скрипта из `scripts` |
| `layer` | Слой отрисовки |
| `hide` | Скрыть объект |

## Редактор

Редактор открывает окно и рисует:

- верхнюю панель с названием, версией и описанием проекта;
- разделы **objects**, **scripts**, **textures**, **fonts**;
- кнопку **run**;
- нижнюю панель с типом выбранного значения, состоянием отладки и строкой исключения/подсказки.

### Возможности редактора

- Просмотр и редактирование списков объектов, скриптов, текстур и шрифтов.
- Выбор элемента и редактирование его свойств.
- Создание объектов, текста, пустышек, скриптов, текстур и шрифтов.
- Удаление элементов.
- Переименование ключей.
- Приведение значений к типам:
  - число;
  - строка;
  - булево значение;
  - список чисел;
  - список строк;
  - `None`.
- Прокрутка списков и панели свойств.
- Настройка палитры редактора через `project.json` или CLI.
- Подсказки по API и горячим клавишам.

## Игровой рантайм

Рантайм загружает `project.json` и файл данных, после чего:

1. Сортирует `game_objects` по `layer` в обратном порядке.
2. Загружает шрифты, текстуры и скрипты.
3. Создаёт окно и запускает главный цикл.
4. Для каждого объекта выполняет скрипты и отрисовку.

### Поддерживаемые типы объектов

| Тип | Описание |
|---|---|
| `object` | Прямоугольник с цветом и опциональной текстурой |
| `text` | Текст выбранным шрифтом и цветом |
| `empty` | Пустой объект-контейнер или маркер |

### Сцены и камера

- `scene = null` — объект обрабатывается на всех сценах.
- `scene = <id>` — объект обрабатывается только на указанной сцене.
- Камера задаётся смещением `camera_dx` и `camera_dy`, которое прибавляется к координатам при отрисовке.

### Скрипты объектов

Скрипты лежат в `scripts/` и являются Python-файлами.  
Из скрипта удаляется строка:

```python
from crutch.engine import *
```

Для каждого объекта выполняются функции:

```python
def setup(ctx):
    pass

def beforeDraw(ctx):
    pass

def afterDraw(ctx):
    pass
```

- `setup(ctx)` — один раз при старте.
- `beforeDraw(ctx)` — перед отрисовкой.
- `afterDraw(ctx)` — после отрисовки.

> В демо-версии `beforeDraw` фактически вызывается дважды.

## Встроенный API

| Метод | Описание |
|---|---|
| `api.move(ctx, x, y)` | Сместить объект |
| `api.moveTo(ctx, x, y)` | Переместить объект в координаты |
| `api.transform(ctx, width, height)` | Изменить размер |
| `api.pressedKey(key)` | Проверить нажатие клавиши |
| `api.getAttribute(ctx, attr)` | Получить атрибут |
| `api.setAttribute(ctx, attr, value)` | Установить атрибут |
| `api.hide(ctx, value)` | Скрыть или показать объект |
| `api.setGlobal(name, value)` | Установить глобальную переменную |
| `api.getGlobal(name)` | Получить глобальную переменную |
| `api.setCamera(dx, dy)` | Установить смещение камеры |
| `api.setTexture(ctx, texture)` | Установить текстуру |
| `api.getTextureName(ctx)` | Получить имя текстуры |
| `api.getCamera()` | Получить смещение камеры |
| `api.getScene()` | Получить текущую сцену |
| `api.setScene(scene)` | Установить сцену |
| `api.isCollide(ctx, ctx2)` | Проверить столкновение двух объектов |
| `api.isMouseCollide(ctx, btn)` | Проверить столкновение с мышью |
| `api.getMousePos()` | Получить позицию мыши |
| `api.getUuid(ctx)` | Получить UUID объекта |
| `api.getCtxOfUuid(uuid)` | Найти объект по UUID |

Утилита командной строки поддерживает команды:

| Команда | Действие |
|---|---|
| `runClient` | Запустить игровой рантайм |

Пример:

```bash
python main.py runClient
```

## Ограничения демо-версии

- Данные редактора перезагружаются каждый кадр.
- Сохранение выполняется ручной сериализацией словаря с заменами `True/False/None` и кавычек.
- После изменений часто используется `time.sleep`.
- Скрипты выполняются через `exec` на каждом кадре.
- Обработка исключений в редакторе перезапускает главный цикл.
- `beforeDraw` вызывается дважды.

---

> Несмотря на ограничения, проект хорошо подходит как учебный пример JSON-ориентированного редактора и простого 2D-рантайма на Pygame. Его удобно использовать как основу для экспериментов с объектами, сценами, слоями, камерой и скриптами на Python.
